# Changelog

grim-essentials follows grim's version: each release ships the skills as
they stand in that grim release.

## 0.15.0 - 2026-10-23

First marketplace release, for Claude Code, GitHub Copilot, Codex and Qoder.

- `grim-usage`: drive the grim CLI to find, install, update and publish
  AI-agent config.
- `ai-config-authoring`: write and review skills, rules, agents and
  instructions for any coding agent.
- `grim-authoring`: package skills, rules, agents, MCP servers, hooks and
  bundles for `grim build` and `grim release`.
